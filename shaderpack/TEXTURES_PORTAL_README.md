# Texturas Portal / Void para as ferramentas

As texturas void/galáxia para diamond e netherite (sword, pickaxe, axe, shovel, hoe) foram geradas.

Por limitação do upload binário no momento, baixe o zip e coloque os arquivos em:

`src/main/resources/assets/minecraft/textures/item/`

Substitua os arquivos existentes.

O shader WitchMono já está atualizado com o visual void/End.

Depois de colocar as texturas, recompile o client.
