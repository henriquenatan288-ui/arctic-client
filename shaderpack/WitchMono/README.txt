Witch Mono / Void - shader de pós-processamento (Iris)

Visual inspirado no End / portal / galáxia:
- Tom void roxo nas áreas escuras
- Bloom mais forte (brilho de estrelas)
- Vinheta para dar profundidade
- Grain sutil

Instalar:
1. Copie a pasta WitchMono (ou o .zip) para a pasta "shaderpacks" do jogo
2. Abra Iris > Shader Packs e escolha WitchMono

Opções no menu do Iris:
- MONO          → quanto de preto-e-branco (0 = cores, 1 = mono total)
- CONTRAST      → contraste
- BRIGHTNESS    → brilho geral
- VIGNETTE      → escurecimento nas bordas (profundidade)
- GRAIN         → ruído de filme
- BLOOM         → brilho nas partes claras
- VOID_STRENGTH → força do tom void/roxo do End (0 = desligado)

Dica: VOID_STRENGTH 0.4~0.55 + BLOOM 0.5~0.7 fica bem com cara de portal/galáxia.
